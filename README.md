# NdsApp Releases

This repository contains the public release files for NdsApp.

NdsApp is a Revit add-in developed by BIM Nodes.

## Downloads

Download the latest version from the Releases section.

## Installation

1. Download the latest `NdsApp-Setup.exe`.
2. Run the installer.
3. Open Autodesk Revit.
4. NdsApp will be available from the BIM Nodes ribbon tab.

## Notes

This repository only contains public release files.  
The source code is private.
